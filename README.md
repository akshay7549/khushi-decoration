## Website

Decoration collections, bouquets and gifts, wedding car decoration, an event catalogue, photo galleries and an interactive shop map. Includes shop-provided photographs, edited product backgrounds and a labelled brand illustration.

## Run locally

From this directory:

```sh
python -m http.server 8080
```

Open http://localhost:8080/ in a browser. No build step or package installation is required.

## Main files

- `index.html`: content and sections
- `premium.css`: desktop and mobile styling
- `app.js`: category filters, gallery controls and photo viewer
- `assets/`: website images, branding and the PDF catalogue

## Hosting

GitHub Pages publishes the repository root from the `main` branch. Use relative asset paths so the website works under `/khushi-decoration/`.
